# 2. 连上去

[**连接**](command:bastion.connect) —— 选一个档案，扩展会：

1. 连上堡垒机，让你输密码
2. 如果堡垒机要 MFA：**在终端里**问你要动态码（带倒计时，不弹窗打断你）
3. 让你选目标机（堡垒机模式）→ 弹出账号菜单 → 落到目标机 shell

## 连接复用

连上之后：

- **再开会话免 MFA**：终端右上角的 `+`，或命令面板搜「新建会话」
- **状态栏能看到**：`$(terminal-bash) Bastion N 会话`，悬停可以看每个会话属于哪条连接、已连多久
- 点底栏任意 Bastion 格子 → 打开右侧「**总览与进度**」面板

[**打开总览与进度面板**](command:bastion.showOverview)

## 同一个改动要在几台机器上各敲一遍？

[**广播输入**](command:bastion.toggleBroadcast) —— 勾几台会话，之后在任意一个里敲的键都会同步过去。

默认是**原样同步**（逐键镜像，**在 vim 里改配置文件靠它**）；底栏广播开着时会多出一格
「原样同步」，[点一下就切成「整行发送」](command:bastion.toggleBroadcastMode)（只在按回车时发整行，
适合给几台机器各敲一条命令）。也可以直接在右侧「总览与进度」面板里逐台点「加入广播」。

开着的时候底栏会常驻警告色的「广播 N 台」（点它就能改或关）：**忘了它开着是有风险的**，
在测试机上敲的东西会在生产机上一字不差地跑一遍。MFA 动态码、AI 执行、部署注入都不会被广播。

## 连不上时

看日志，里面会写清每一步的判定（菜单识别命中没有、卡在哪一步）：

[**打开日志**](command:bastion.showLog)

> 堡垒机菜单文案各家用得不一样。认不出来时日志会把**当时屏幕上的原文整段打出来**，
> 照着它改设置就行（见下一步）。

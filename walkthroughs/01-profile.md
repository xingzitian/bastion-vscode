# 1. 建一个连接档案

档案 = 「用哪个账号、连哪台堡垒机、怎么认证」。密码不会写进文件，存在系统加密存储里。

[**新建档案**](command:bastion.addProfile)

## 填写要点

| 字段 | 怎么填 |
|---|---|
| **名称** | 自己看得懂就行，比如 `生产`、`测试集群`。后面部署任务就是按这个名称找档案的 |
| **主机** | 堡垒机地址（堡垒机档案）或目标机地址（直连档案） |
| **用户名** | 堡垒机账号 |
| **认证方式** | `password` 最常用；堡垒机要求 MFA 时，连接过程中会在**终端里**问你要动态码 |
| **模式** | `bastion` = 过堡垒机菜单选目标机；`direct` = 直接连这台机器 |

## 省事的做法

档案全在 `~/.bastionshell/profiles.jsonc`，**直接改文件比点界面快**：

[**打开档案文件**](command:bastion.openProfilesFile)

> 一次认证（密码 + MFA）之后，这条连接会被复用 —— 之后开多少个会话都不用再输 MFA。
> 这是本扩展跟普通 SSH 客户端最大的区别。

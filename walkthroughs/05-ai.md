# 让 AI 也能操作服务器

扩展向 VS Code 里的 AI（Copilot Chat、Cursor、CodeBuddy 等）暴露了 5 个工具：

| 工具 | 干什么 |
|---|---|
| `bastion_listProfiles` | 列出有哪些连接档案 |
| `bastion_connect` | 连到某台机器并开会话 |
| `bastion_exec` | 在**已连接的会话**里执行命令并拿回输出 |
| `bastion_listSessions` | 看当前有哪些会话 |
| `bastion_habits` | 记住「这台机器上你习惯怎么干活」（提权方式、常用目录） |

于是在聊天里可以直接说：

> 「连到生产那台，看看 nginx 为什么起不来」

AI 会自己去连、去执行、把输出读回来分析。**高危命令会被拦下来**（`rm -rf /` 之类），
不想被拦可以在 `~/.bastionshell/dangerRules.jsonc` 里改规则。

[**打开高危命令规则文件**](command:bastion.openDangerRulesFile)

## 把终端现场发给 AI

- 终端里选中文字 → `Ctrl+Alt+I` 直接送进聊天
- 没选中 → `Ctrl+Alt+Shift+I` 发最近若干行输出

[**打开日志**](command:bastion.showLog)
